# Инструкция: Публикация дашборда на GitHub Pages

## Шаг 1: Создать аккаунт GitHub (если нет)

1. Перейдите на https://github.com
2. Нажмите **"Sign up"** (Регистрация)
3. Введите email, пароль, имя пользователя
4. Подтвердите email

## Шаг 2: Создать новый репозиторий

1. Войдите в GitHub
2. Нажмите зелёную кнопку **"+"** в правом верхнем углу → **"New repository"**
3. Заполните поля:
   - **Repository name**: konkurs-godovaya-oplata (или любое другое название)
   - **Description**: Дашборд конкурса по переводу на годовую оплату
   - **Public** (публичный) — выберите это!
   - **Add a README file** — НЕ ставьте галочку (у нас уже есть README)
4. Нажмите **"Create repository"**

## Шаг 3: Загрузить файлы

### Вариант A: Через веб-интерфейс (проще)

1. На странице нового репозитория нажмите **"uploading an existing file"**
2. Перетащите файлы из папки:
   C:\Users\d.n.kasinskaya\.local\share\bitrix24-cowork\cowork\github-pages\
   (файлы: index.html и README.md)
3. В поле "Commit changes" напишите: Initial commit: dashboard files
4. Нажмите **"Commit changes"**

### Вариант B: Через Git (для продвинутых)

`ash

git branch -M main

`

## Шаг 4: Включить GitHub Pages

1. В репозитории перейдите во вкладку **"Settings"** (Настройки)
2. В левом меню выберите **"Pages"**
3. В разделе **"Source"** (Источник):
   - Выберите ветку: **"main"**
   - Папка: **"/ (root)"**
   - Нажмите **"Save"**
4. Подождите 1-2 минуты
5. Страница обновится и покажет ссылку вида:
   https://[ваш-username].github.io/konkurs-godovaya-oplata/

## Шаг 5: Проверить и поделиться

1. Откройте полученную ссылку в браузере
2. Убедитесь, что дашборд отображается корректно
3. Отправьте ссылку коллегам!

## Как обновлять данные в будущем

### Через веб-интерфейс:

1. Откройте файл index.html в репозитории
2. Нажмите карандаш (✏️) для редактирования
3. Найдите строку: const competitionData = [...]
4. Замените данные на актуальные
5. Внизу напишите комментарий: Update data: [дата]
6. Нажмите **"Commit changes"**
7. Изменения появятся на сайте через 1-2 минуты

---

## Важные замечания

- Репозиторий должен быть **Public** (публичным), иначе GitHub Pages не работает
- Ссылка будет доступна ВСЕМ, у кого есть URL (не только коллегам)
- Данные обновляются вручную — нужно редактировать файл и делать commit
- Если нужно скрыть данные от посторонних — используйте приватный репозиторий + другой хостинг

## Помощь

Если возникнут проблемы:
- Проверьте, что репозиторий публичный
- Убедитесь, что файл называется именно index.html
- Подождите 2-3 минуты после включения Pages
- Проверьте консоль браузера (F12) на ошибки
