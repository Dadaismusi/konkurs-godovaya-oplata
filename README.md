# Конкурс: Перевод на годовую оплату

Интерактивный дашборд для отслеживания конкурса по переводу клиентов с месячного на годовой тариф.

## Описание

- **Период**: 1 августа - 30 сентября 2026
- **Участники**: 6 менеджеров
- **База**: 169 порталов Enterprise с окончанием тарифа в августе-сентябре 2026
- **Исключение**: София Ведищева

## Как обновить данные

1. Откройте файл index.html
2. Найдите строку: const competitionData = [...]
3. Замените содержимое массива на актуальные данные
4. Сохраните и закоммитьте изменения
